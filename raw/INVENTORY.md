## 2. 歷屆術科試題（raw/practical/）— 目前為空，原因如下

在「PastQuestions.aspx」各梯次詳細列表中，每一列均有「學科」「術科」兩欄下載連結；
逐一檢查上述 17 個梯次（含全部下載到的 session 明細頁 HTML，見 `raw/_evidence/session_html/`）
後發現：**營造工程管理（甲級／乙級）在所有梯次中的「術科」欄位皆為空**，
且依同站其他職類使用的檔名規則（`{職類代號}{級別碼}-2.pdf`）反向嘗試組出的 URL 一律回傳 404
（測試記錄見 `raw/_evidence/sessions_result.json`）。

僅在 113年度第2梯次 詳細頁中查得一份「113年度第2梯次全國技術士技能檢定營造工程管理甲級**術科試題疑義處理修正公告**」
（`DLowFileQ/Sub/2024101510442910.pdf`，屬疑義處理公告而非原始試題），可佐證該職類確實有術科測試，
但官方**並未在「歷屆試題」系統中逐梯次公開術科原始試題 PDF**。

**替代來源（已下載至 raw/bank/，見下表）**：官網首頁「測試參考資料」提供本職類甲級「術科」的
**現行公版應檢參考資料**與**最新修訂對照表**，內容即為術科測試所依據的題庫／規範母體，
是目前唯一可公開取得、與「術科試題」性質最接近的官方文件。若確實需要「逐年逐梯次」的術科考卷，
需向勞動部技能檢定中心以正式管道申請，非本網站公開下載範圍——**此為需要人工判斷/申請的阻礙事項**。

| 項目 | 狀態 | 原因 |

| 105–115 各梯次 術科試題（逐梯次） | ✗ 缺 | 官網歷屆試題系統未公開此職類術科逐梯次原始試題（結構性缺漏，非下載失敗） |

## 5. 阻礙與待人工處理事項

1. **術科逐梯次原始試題完全缺漏**（見上節），這是網站結構性限制，非下載失敗；如需逐年術科考卷，
   須向勞動部技能檢定中心提出正式申請或另尋管道。
2. 原始網站對 `requests`/`curl` 發出的 **POST** 請求會被 F5 WAF 以「Request Rejected」擋下
   （純 GET 請求，如靜態檔案下載，不受影響）；本次改用真實瀏覽器（Claude Browser／Chrome）
   模擬點擊 ASP.NET `__doPostBack` 逐頁翻頁，取得各梯次的 `yserno` 識別碼後，
   再用一般 `curl`/`requests` 對已知的靜態檔案 URL 直接下載，全程未使用任何自動化繞過驗證碼或安全機制。
3. `raw/_evidence/` 保留了完整的 32 個梯次詳細頁 HTML 快照與程式化掃描結果 JSON，
   供之後複核或重新確認「術科缺漏」結論。
