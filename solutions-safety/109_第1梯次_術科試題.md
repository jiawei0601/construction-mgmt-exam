## 第一題（配分：20分）
### 題目
某營造工地屬丁類工作場所，依危險性工作場所審查及檢查辦法規定，試回答下列問題：
(一) 事業單位向勞動檢查機構申請審查丁類工作場所時，對於那3種特殊狀況之營造工程，得報經勞動檢查機構同意後，分段申請審查。(3分)
(二) 事業單位應於事前由那5類人員組成施工安全評估小組實施評估？(10分)
(三) 對於丁類工作場所審查結果，除可歸責於事業單位外，勞動檢查機構應於受理申請後幾日內，以書面通知事業單位。(1分)
(四) 對於施工安全評估報告書之內容，請列舉6項。(6分)

### 參考擬答
**(一)** 對於下列3種特殊狀況之營造工程，事業單位得報經檢查機構同意後，分段申請審查：
1. 工程內容較複雜者。
2. 工期較長者。
3. 施工條件變動性較大者。

**(二)** 事業單位應於事前由下列5類人員組成施工安全評估小組實施評估：
1. 工作場所負責人。
2. 施工安全評估人員（曾受國內外施工安全評估專業訓練或具有施工安全評估專業能力，持有證明文件，且經中央主管機關認可者；未置者得以完成訓練之工業安全技師併同建築師、土木工程技師、結構工程技師、大地工程技師或水利工程技師之一任之）。
3. 專任工程人員。
4. 依職業安全衛生管理辦法設置之職業安全衛生人員。
5. 工作場所作業主管（含承攬人之人員）。

**(三)** 檢查機構應於受理申請後30日內，以書面通知事業單位。

**(四)** 施工安全評估報告書之內容，可列舉如下6項（依附件十五及製程／施工安全評估通用架構）：
1. 工程概要（含施工計畫書內容摘要、施工範圍、期程）。
2. 施工方法及程序說明。
3. 潛在危害因素之辨識及評估結果。
4. 危害預防對策及安全衛生設施配置。
5. 專任工程人員、相關執業技師或開業建築師之簽章文件。
6. 緊急應變處置措施及相關管理計畫。

### 法規與依據
- 《危險性工作場所審查及檢查辦法》第17條：丁類工作場所申請審查應檢附施工計畫書、施工安全評估報告書；工程內容較複雜、工期較長、施工條件變動性較大等特殊狀況之營造工程，得分段申請審查。
- 《危險性工作場所審查及檢查辦法》第18條：施工安全評估小組由工作場所負責人、施工安全評估人員、專任工程人員、職業安全衛生人員、工作場所作業主管（含承攬人之人員）等5類人員組成。
- 《危險性工作場所審查及檢查辦法》第19條：丁類工作場所審查結果，檢查機構應於受理申請後30日內以書面通知事業單位，可歸責於事業單位者不在此限。
- 《危險性工作場所審查及檢查辦法》第17條：施工安全評估報告書內容如附件十五（附件內容本身未見於現行法規全文語料，(四)之答案係依一般施工安全評估報告書通用架構彙整，作答時仍應以最新公告之附件十五格式為準）。

### 考點提示
本題考危險性工作場所四分類中丁類（營造工程）的審查程序，重點在於分段審查的3種特殊情形、施工安全評估小組的5類組成人員（尤其是「施工安全評估人員」的資格認定與替代方式）、法定30日書面通知期限，以及施工安全評估報告書的內容架構。常見失分點：把丁類分段申請的條件與丙類、乙類的規定混淆；漏答施工安全評估小組中「工作場所作業主管（含承攬人之人員）」；誤把30日答成45日（45日為乙、丙類工作場所之期限）。

## 第二題（配分：20分）
### 題目
依職業安全衛生設施規則規定，試回答下列問題：
(一) 請說明「氣體集合熔接裝置」及「氣體集合裝置」。(8分)
(二) 為避免漏電而發生感電危害，雇主應在那3種狀況下於各該電動機具設備之連接電路上設置適合其規格，具有高敏感度、高速型，能確實動作之防止感電用漏電斷路器？(6分)
(三) 對於作業場所有易燃液體之蒸氣、可燃性氣體或爆燃性粉塵以外之可燃性粉塵滯留，而有爆炸、火災之虞者，雇主除應依危險特性採取通風、換氣、除塵等措施外，應再依那3項規定辦理？(6分)

### 參考擬答
**(一)**
- 氣體集合熔接裝置：指由氣體集合裝置、安全器、壓力調整器、導管、吹管等所構成，使用可燃性氣體供金屬之熔接、熔斷或加熱之設備。
- 氣體集合裝置：指由導管連接10個以上之可燃性氣體容器之裝置；或由導管連結9個以下之可燃性氣體容器之裝置中，其容器容積合計，氫氣或溶解性乙炔之容器在400公升以上，其他可燃性氣體容器在1,000公升以上者。

**(二)** 雇主應於下列3種狀況，於電動機具設備之連接電路上設置具高敏感度、高速型、能確實動作之防止感電用漏電斷路器：
1. 使用對地電壓在150伏特以上之移動式或攜帶式電動機具。
2. 於含水或被其他導電度高之液體濕潤之潮濕場所、金屬板上或鋼架上等導電性良好場所，使用移動式或攜帶式電動機具。
3. 於建築或工程作業使用之臨時用電設備。

**(三)** 除通風、換氣、除塵等措施外，應再依下列3項規定辦理：
1. 指定專人對於蒸氣、氣體之濃度，於作業前測定之。
2. 蒸氣或氣體之濃度達爆炸下限值之30%以上時，應即刻使勞工退避至安全場所，並停止使用煙火及其他為點火源之虞之機具，並應加強通風。
3. 使用之電氣機械、器具或設備，應具有適合於其設置場所危險區域劃分使用之防爆性能構造。

### 法規與依據
- 《職業安全衛生設施規則》第17條：氣體集合熔接裝置與氣體集合裝置之定義。
- 《職業安全衛生設施規則》第243條：3種應設置防止感電用漏電斷路器之狀況。
- 《職業安全衛生設施規則》第177條：可燃性粉塵滯留場所應辦理之3項規定。

### 考點提示
本題考職安設施規則中電氣安全與火災爆炸預防兩大主題。(一)重點在區分「氣體集合裝置」本身（容器數量與容積門檻）與「氣體集合熔接裝置」（含安全器、壓力調整器等周邊構件的完整系統）；作答需寫出400公升（氫氣、溶解性乙炔）與1,000公升（其他可燃性氣體）兩個容積門檻，這是常見漏答處。(二)注意150伏特係「對地電壓」而非線間電壓。(三)容易與可燃性氣體、易燃液體蒸氣（第177條前段）混淆，須留意本條係規範「易燃液體之蒸氣、可燃性氣體或爆燃性粉塵以外之可燃性粉塵」，且30%為常考數字。

## 第三題（配分：20分）
### 題目
依職業安全衛生管理辦法規定，試回答下列問題：
(一) 請說明那4種事業單位應參照中央主管機關所定之職業安全衛生管理系統指引，建置適合該事業單位之職業安全衛生管理系統？(8分)
(二) 前述管理系統應包括那5項安全衛生事項？(10分)
(三) 前述安全衛生管理之執行應作成紀錄，並保存幾年？(2分)

### 參考擬答
**(一)** 下列4種事業單位，雇主應依國家標準同等以上規定，建置適合該事業單位之職業安全衛生管理系統：
1. 第一類事業勞工人數在200人以上者。
2. 第二類事業勞工人數在500人以上者。
3. 有從事石油裂解之石化工業工作場所者。
4. 有從事製造、處置或使用危害性之化學品，數量達中央主管機關規定量以上之工作場所者。

**(二)** 前述管理系統應包括下列5項安全衛生事項：
1. 風險評估：於引進或修改製程、作業程序、材料及設備前，評估其職業災害之風險，並採取適當之預防措施。
2. 採購與發包管理：機械、設備、器具、物料、原料及個人防護具等之採購、租賃契約，及營繕工程規劃、設計、施工、監造之發包契約，均應納入符合法令之職業安全衛生具體規範。
3. 承攬管理：以事業之全部或一部分交付承攬，或與承攬人分別僱用勞工於同一期間、同一工作場所共同作業時，應就承攬人之安全衛生管理能力、危害通報、教育訓練等事項訂定承攬管理計畫。
4. 緊急應變：依潛在風險訂定緊急狀況預防、準備及應變之計畫，並定期實施演練。
5. 管理績效之審查及表揚：管理績效良好並經中央主管機關認可者，得予分級公開表揚，以持續精進管理系統。

**(三)** 應作成紀錄，並保存3年。

### 法規與依據
- 《職業安全衛生管理辦法》第12-2條：4種應建置職業安全衛生管理系統之事業單位；執行紀錄保存3年。
- 《職業安全衛生管理辦法》第12-3條：風險評估。
- 《職業安全衛生管理辦法》第12-4條：採購、發包契約規範。
- 《職業安全衛生管理辦法》第12-5條：承攬管理計畫。
- 《職業安全衛生管理辦法》第12-6條：緊急應變計畫及演練。
- 《職業安全衛生管理辦法》第12-7條：管理績效認可及表揚。

### 考點提示
本題核心在職業安全衛生管理辦法第12條之2至第12條之7所建構的「管理系統」專章，(一)須留意人數門檻（第一類200人、第二類500人）與另外兩種「不論人數」即應建置的特殊工作場所（石化裂解、危害性化學品達規定量）。(二)為條文結構性考點，5項事項依序對應12-3至12-7條，答題時建議依條文順序條列以避免遺漏。(三)保存年限3年是本辦法多處重複出現的一致規定，亦是職安衛管理辦法的高頻考點數字。

## 第四題（配分：20分）
### 題目
依起重升降機具安全規則規定，移動式起重機之使用，以吊物為限，不得乘載或吊升勞工從事作業。但從事貨櫃裝卸、船舶維修、高煙囪施工等尚無其他安全作業替代方法，或臨時性、小規模、短時間、作業性質特殊，經採取防止墜落等措施者，不在此限。
試回答下列問題：
(一) 前述但書所定防止墜落措施，應辦理那4種規定事項？(8分)
(二) 移動式起重機從事垂直高度多少公尺以下之高處作業，不適用前述但書規定。(2分)
(三) 承上題，那些作業者，不在此限？(2分)
(四) 以搭乘設備乘載或吊升勞工時，該搭乘設備應依那4項規定辦理？(8分)

### 參考擬答
**(一)** 防止墜落措施應辦理之核心事項如下：
1. 以搭乘設備乘載或吊升勞工，並防止其翻轉及脫落。
2. 搭乘設備應設置安全母索或防墜設施，並使勞工佩戴安全帽及符合國家標準CNS 14253-1同等以上規定之全身背負式安全帶。
3. 搭乘設備之使用不得超過限載員額。
4. 搭乘設備自重加上搭乘者、積載物等之最大荷重，不得超過該起重機作業半徑所對應之額定荷重之50%。

（註：現行《起重升降機具安全規則》第35條第2項對防止墜落措施實際已列有6款規定，除上列4項外，另增訂「搭乘設備下降時應採動力下降之方法」及「垂直高度超過20公尺之高處作業，禁止使用直結式搭乘設備（設有無線電通訊聯絡及作業監視或預防碰撞警報裝置者不在此限）」2款，作答時建議依現行條文完整列出6款以符合最新規定。）

**(二)** 20公尺以下。

**(三)** 使用道路或鄰接道路作業者，不在此限（仍應適用但書防止墜落措施之規定）。

**(四)** 搭乘設備應依下列4項規定辦理：
1. 搭乘設備應有足夠強度，其使用之材料不得有影響構造強度之損傷、變形或腐蝕等瑕疵。
2. 搭乘設備周圍應設置高度90公分以上之扶手，並設中欄杆及腳趾板。
3. 搭乘設備之懸吊用鋼索或鋼線之安全係數應在10以上；吊鏈、吊帶及其支點之安全係數應在5以上。
4. 應依搭乘設備之構造及材質，計算積載之最大荷重，並於搭乘設備之明顯易見處，標示自重及最大荷重。

### 法規與依據
- 《起重升降機具安全規則》第35條：移動式起重機以吊物為限不得乘載勞工之原則及例外，暨防止墜落措施之規定事項（現行條文為6款）。
- 《起重升降機具安全規則》第37條：移動式起重機從事垂直高度20公尺以下之高處作業，不適用第35條第1項但書規定；但使用道路或鄰接道路作業者不在此限。
- 《起重升降機具安全規則》第36條：搭乘設備應依規定辦理之4項事項。

### 考點提示
本題整組考的是移動式起重機「以人代物」吊升作業的特別安全管理，重點在防止墜落措施與搭乘設備規格兩組規定不可混淆：前者規範「作業方式」（限載員額、荷重上限、安全母索與個人防護具），後者規範「設備本體」（強度、扶手、鋼索安全係數、標示）。20公尺與「使用道路或鄰接道路作業」的除外規定，是與第四題(一)相互呼應的追加規範，答題時要留意題目已將此獨立列為(二)(三)小題，代表出題當時的條文架構把此列為單獨規定，作答時仍應忠實回答current條文之數字結論。安全係數「懸吊用鋼索10以上、吊鏈5以上」為常考數字，勿與吊掛用鋼索（安全係數6以上，見第65條）搞混。

## 第五題（配分：20分）
### 題目
依Jone's理論得知可燃性物質之爆炸下限(LEL)為理論混合比例值(Cst)之0.55倍(LEL=0.55Cst)，假設空氣中氧氣之體積百分比為21%，試回答下列問題：
(一) 計算乙烷(C2H6)之理論混合比例值(Cst)(10分)與其爆炸下限(5分)。
(二) 若乙烷之爆炸上限為12.4%，計算乙烷之相對危險指數。(5分)

### 參考擬答
**(一) 理論混合比例值 Cst 與爆炸下限 LEL**

乙烷完全燃燒反應式：
C₂H₆ + 3.5 O₂ → 2CO₂ + 3H₂O

即完全燃燒1莫耳乙烷需要3.5莫耳氧氣（n = 3.5）。

依Jone's理論，理論混合比例值計算公式為：
Cst = 100 / [(1/0.21) × n + 1]

代入 n = 3.5、氧氣體積百分比21%：
Cst = 100 / [(1/0.21) × 3.5 + 1]
   = 100 / [4.7619 × 3.5 + 1]
   = 100 / [16.667 + 1]
   = 100 / 17.667
   ≈ **5.66 %**

爆炸下限：
LEL = 0.55 × Cst = 0.55 × 5.66% ≈ **3.11 %**

（驗算：乙烷之實測LEL約為3.0%左右，與計算值3.11%相符，數量級合理。）

**(二) 相對危險指數**

相對危險指數之定義為：
相對危險指數 = (UEL − LEL) / LEL

已知 UEL = 12.4%，LEL ≈ 3.11%：
相對危險指數 = (12.4 − 3.11) / 3.11
       = 9.29 / 3.11
       ≈ **2.99（約3）**

### 法規與依據
本題屬工業安全工程之爆炸特性計算題，Jone's理論（理論混合比例值與爆炸下限之經驗關係式）及相對危險指數（火災爆炸危險度指標）屬工業安全工程學理範疇，非法規條文規定事項，故不列法規條號，作答時應以計算過程之正確性與合理性為評分核心。

### 考點提示
