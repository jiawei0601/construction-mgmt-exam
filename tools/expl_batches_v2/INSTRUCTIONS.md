# 解析批次作業指令（職安三職類共用）

讀取 C:\CLAUDE\construction-mgmt-exam\tools\expl_batches_v2\{批次檔名}.json（每題 {id, stem, options, answer}，answer 為官方正解選項鍵陣列），寫出 C:\CLAUDE\construction-mgmt-exam\tools\expl_out_v2\{相同檔名}.json。

## 輸出格式（UTF-8 JSON，涵蓋輸入檔全部題目，一題都不能漏）
{"題目id": {"c": "正解理由", "w": {"選項鍵": "錯因", ...}, "ref": "法規名稱§第X條" 或 "法規名稱" 或 null}, ...}

## 品質紅線（違反會被腳本退件重做）
- 每題必須有實質內容。禁止佔位符、「X」「略」「同上」、空泛的「不正確/錯誤」。
- c＝解釋官方答案為何正確，8–60字；複選題逐一講齊每個正確選項理由（可到90字）。
- w＝answer 以外每個選項各一句具體錯因，6–40字（錯在哪個觀念/數值/法規/危害類型）。
- ref＝法規題才填：條號有把握寫「法規名稱§第X條」；只確定法規名就只寫名稱；非法規題 null。**嚴禁猜條號**。
- 官方答案不容質疑，以解釋官方答案為準。全繁體中文。
- 題幹含「（如圖）」的題照文字與選項內容解釋即可。

## 省 token 紀律
只 Read 輸入檔一次、Write 輸出檔一次（題數多可分兩次 Write 正確接合，不准交佔位符）。最後用 python -c 驗證：JSON 可解析、題數與輸入一致、無 c<8字、無 w<6字。回報只回四個數字：「題數/含ref數/最短c長度/最短w長度」。
