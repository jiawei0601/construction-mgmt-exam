## 引用頻率驗證方法
在 construction-mgmt-exam 目錄執行：
  grep -o "關鍵字" data/questions.js data/osh-questions.js data/safety-questions.js data/hygiene-questions.js | wc -l
用以確認法規在四份題庫（合計6,442題）中的出現次數，決定優先蒐集順序。0 次的母法/子法仍蒐集，
因為考題常以法規精神或概念出題而不逐字寫出法規全名，且供 expl_merge.py / expl_merge_multi.py
事後補接條文時使用（含 name-only ref 模糊比對）。

## 缺漏與已知限制
- 採購契約要項不在全國法規資料庫（law.moj.gov.tw）API 範圍內（該庫僅收「法律」與「命令」
  兩種位階），改採官方共用法規系統（lawweb.pcc.gov.tw）網頁全文，非腳本自動化下載，
  未來如需重新抓取須手動更新此檔。
- 「職業災害勞工保護法」實務上已於2022年由「勞工職業災害保險及保護法」實質取代，但
  law.moj Open API 快取未標記 LawAbandonNote（仍視為現行），故沿用既有腳本邏輯原樣收錄；
  若該法規題目引用有時效性疑義，解析時應優先參照後者。
- 若日後 haiku 解析 agent 標註的 ref 法規不在本清單範圍內，expl_merge.py / expl_merge_multi.py
  會將該筆記入 tools/expl_out*/UNMATCHED*.txt，屆時可視情況追加進
  tools/build_law_corpus.py 的 TARGETS 清單重跑（腳本冪等、可重複執行覆寫）。
- 法規版本以下載當下（2026-07-06 快取／2026-08-04 手動抓取確認）之全文為準；若考題引用舊版
  條文內容有出入，屬法規修正後版本差異，非本次蒐集疏漏。
- 技術規範類（如CNS國家標準、鋼結構設計規範等）不在國家法規資料庫收錄範圍，本清單不含，
  該類 ref 於 UNMATCHED 中僅顯示名稱，無法接原文。
