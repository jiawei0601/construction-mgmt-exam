# 營造工程管理甲級 考古題題庫與線上測驗

營造工程管理（職類代號 18000）甲級技術士技能檢定考古題整理專案，涵蓋**學科題庫＋線上模擬測驗**與**術科歷屆試題參考詳解**兩大部分，純靜態網頁、無需伺服器與資料庫，開啟 `index.html` 即可使用。

線上網址：`https://jiawei0601.github.io/construction-mgmt-exam/`（佔位，尚未發佈）

## 專案內容

- **`index.html`**：學科題庫線上測驗系統
  - 模擬考模式：比照正式學科考試抽 60 題單選＋20 題複選（單選 1 分／複選 2 分，全對才給分，滿分 100、60 分及格），單題線性作答、答完自動前進、不可回頭修改。
  - 錯題加強模式：從錯題本抽題複習，連續答對 2 次自動移出錯題本。
  - 成績紀錄與科目弱點統計、匯出／匯入作答紀錄（JSON）。
- **`practical.html`**：術科歷屆試題參考詳解（民國 105–111 年，按年度摺疊瀏覽）。

## 學科題庫統計

`data/questions.js` 共 **1,512 題**：

| 來源 | 題數 |
|---|---|
| 官方題庫（甲級題庫＋共同科目以外之專業科目） | 905 |
| 共同科目（90006–90009） | 400 |
| 歷屆試卷獨有（題庫查無對應原題，僅見於歷屆考卷） | 207 |
| **合計** | **1,512** |

分類統計：專業科目 1,112 題（905＋207）、共同科目 400 題；單選 1,311 題、複選 201 題。

驗證方式：以官方 16 份歷屆學科試卷（每份 60 單選＋20 複選）逐題比對 `appearances`（出現年度／梯次／題號），並執行硬規則驗證（每題 4 個選項、`answer` 皆存在於選項 key、複選答案長度 ≥2 等），全數通過、0 項異常。詳細生成紀錄見 `data/PARSE_REPORT.md`。

## 術科範圍

術科詳解涵蓋民國 **105–111 年**（共 7 個年度），每年當日配發 A／B／C／D 四份平行試卷，每卷各自獨立、共 5 大題、每題配分 20 分（單卷合計 100 分）；本專案依卷別＋題序，將四卷共 20 大題完整收錄於各年度頁面。

**民國 112–115 年缺**：經窮盡搜尋官方系統、第三方教學網／部落格、論壇心得文等管道，確認上述 4 個年度並無任何公開流通之術科試題原文可考（112 年官方僅公開學科直連、無術科檔名；113 年僅有一份試題疑義處理修正公告非試題本文；114、115 年因較晚近，尚未見補習班／部落格圈整理流出）。詳細調查紀錄見 `raw/practical/SOURCES.md`。

## 資料來源

- **學科題庫暨歷屆試卷**：勞動部勞動力發展署技能檢定中心官網（`owinform.wdasec.gov.tw`，原 `techbank.wdasec.gov.tw`）。
- **術科歷屆試題**：105–111 年官方系統查詢介面本身未逐梯次公開術科原始試題，改由第三方教學網站（ACI建築營造室內工程管理教學網）取得掃描件，其中 109–111 年並取得官方主機一手 PDF 交叉驗證（110 年並附完整逐字轉錄），詳見 `raw/practical/SOURCES.md`。
- 依《著作權法》第 9 條，依法令舉行之各類考試「試題」非著作權標的，本專案僅收錄題目原文；第三方之詳解、解答則有著作權，一律不收錄他人解答內容。

## 免責聲明

- **學科題庫答案**：取自官方公告之學科試題暨答案 PDF，為官方標準答案。
- **術科參考詳解**（`practical.html`）：**為 AI 彙整之參考擬答，非官方標準答案**。官方不公布術科標準答案，本詳解僅供讀者理解考點方向與相關法規依據，法規條號與內容請以最新公告版本為準，正式作答仍應以授課教師意見及最新法規為準。

## 本機使用方式

無需安裝任何套件，直接以瀏覽器開啟 `index.html` 或 `practical.html` 即可（本機檔案系統 `file://` 開啟即可運作；若瀏覽器對本機檔案的 `<script src>` 有限制，也可用任一靜態伺服器開啟，例如 `python -m http.server`）。

## 資料重建方式

`tools/` 目錄下為題庫與詳解頁的重建腳本：

- `tools/fetch_sessions.py`：掃描官網各梯次場次序號（`yserno`），列出本職類涵蓋之考試梯次。
- `tools/download_subject.py`：下載歷年「學科試題暨答案」PDF 至 `raw/subject/`。
- `tools/build_practical.py`：讀取 `solutions/105.md`～`111.md`（術科參考詳解原始 Markdown），組成靜態頁面 `practical.html`。執行方式：
  ```
  python tools/build_practical.py
  ```
  （需先 `pip install markdown`；產出的 HTML 為 build time 靜態轉換結果，頁面本身不依賴任何 JS 轉換或外部 CDN。）

`data/questions.js`（學科題庫本體）與 `solutions/*.md`（術科詳解原始內容）為既有產出資料，其解析與撰寫紀錄分別見 `data/PARSE_REPORT.md` 與 `raw/practical/SOURCES.md`；如需重新解析原始 PDF 或重新撰寫詳解，請參閱上述報告了解既有流程與規則後再行處理，避免覆蓋既有驗證結果。
